    Data sources

    Change sources
    256 px PNG tiles in Web Mercator, with {z}, {x} and {y} in the URL. The server must allow cross-origin requests.
    Accessibility

    topowall is built to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA: everything works with a keyboard and screen readers, the map can be moved and zoomed without dragging, and text and controls keep enough contrast.

    If something doesn't work for you, please tell us on GitHub (opens in a new tab).

    Privacy
    • No accounts, cookies, analytics or tracking. This site has no server-side code; it only sends these files.
    • Maps are drawn on your own device. Your browser downloads elevation tiles directly from the elevation source above, and sends place searches to the search service when you press Enter. Those services see your IP address, as any website does.
    • The place you're looking at is kept in the address after #, which browsers never send to servers.
    • Your settings and the themes you save stay in this browser only. Backups are files you download and open yourself.
